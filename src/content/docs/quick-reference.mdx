| Type | Folder | Nature | File structure |
|---|---|---|---|
| <span class="stage-badge stage-idea">Idea</span> | `Idea/` | Unverified, volatile | One file per idea |
| <span class="stage-badge stage-knowledge">Knowledge</span> | `Knowledge/` | Verified, stable fact | One file per fact |
| <span class="stage-badge stage-decision">Decision</span> | `Decision/` | Context-bound reasoning | One file per decision |
| <span class="stage-badge stage-lesson">Lesson</span> | `Lesson.md` | Retrospective, honest | One running log per domain |
| Cheatsheet | `Cheatsheet/` | Quick-recall reference | One file per topic |
| Assignment | `Assignment/` | Deliverable, links to Decisions | One file per assignment |
| Course | `Course/<Name>/` | Given materials | Flat dump, no sub-nesting |

See the [Frontmatter schema](./frontmatter-schema/) for field-level detail, or
[Folder structure](./folder-structure/) for the full directory tree.
